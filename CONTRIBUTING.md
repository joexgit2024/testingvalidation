# Contributing to Serial Number Validation System

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/testingvalidation.git`
3. Create a feature branch: `git checkout -b feature-name`
4. Make your changes
5. Test thoroughly
6. Commit your changes: `git commit -am 'Add new feature'`
7. Push to the branch: `git push origin feature-name`
8. Submit a pull request

## Development Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Test your changes in the browser at `http://localhost:5000`

## Code Style

- Follow PEP 8 Python style guidelines
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions focused and small

## Testing

- Test all validation logic thoroughly
- Verify file upload functionality
- Check drag and drop features
- Test with various Excel file formats
- Ensure error handling works correctly

## Reporting Issues

When reporting issues, please include:
- Description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable
- Browser and OS information

## Feature Requests

Before submitting feature requests:
- Check if the feature already exists
- Search existing issues and pull requests
- Provide clear description and use cases
- Consider backward compatibility

Thank you for contributing!

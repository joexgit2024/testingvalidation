How the Validation Works

Validation Logic
  • PASS Results: Part numbers must match AND Rack Bin must end with 'P'
  • FAIL/MAYBE Results: Part numbers must match AND Rack Bin must NOT end with 'P'
  • Exception: If Rack Bin is 'Testwip', it's automatically marked as OK
  • Missing Records: Serial numbers not found in putaway records are flagged
  • Duplicates: Duplicate serial numbers in either file are reported at the end
Required File Format

Both Excel files must contain columns for: Serial Number, Part Number, Test Result, Rack Bin
